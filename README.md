## 🌟 Overview

**fun by .py** ek complete, self-contained interactive Python learning application hai jise đặc biệt BCA / MCA students aur computer science enthusiasts ke liye design kiya gaya hai. Isme comprehensive topic notes, interactive live code editor, 100+ curated MCQ practice questions, real-time timed examination portal, aur official **Raj CS** downloadable printable marksheet/certificate system shamil hai.

## ✨ Key Features

- **🔐 Student Authentication System:**
  - Dynamic registration & login with persistent `localStorage` session state.
  - Personal student profile workspace with custom avatar & registration numbers.

- **📚 Interactive Theory & Code Notes:**
  - Detailed English notes aligned with **VBSPU Jaunpur BCA Syllabus**.
  - Python code syntax highlighting with **One-Click Code Copy** & **Playground Runner**.

- **🧪 Live Python Code Editor:**
  - Built-in lightweight JavaScript-based Python simulator.
  - Test snippets instantly without external environment setup.

- **🎯 100+ High-Quality MCQ Practice Bank:**
  - Categorized under **Basics**, **OOPs**, and **Scripting & File Handling**.
  - Real-time instant answer checking with explanations.

- **📝 Real-Time Online Exam Portal:**
  - Timed 20-Question random examination engine with automated timer.
  - Question flag for review, interactive grid navigation, and progress trackers.

- **📜 Instant Downloadable Marksheet & Certificate:**
  - Generated automatically post-exam with **Raj CS** official institute watermark, grades, score breakdown, and security badge.
  - Built-in **Print / Save as PDF** support.
